# Scrapbook photo collage workflow

Apply this rule only when the user asks to turn supplied photos into a scrapbook, journal, memory-board, travel-diary, or collage cover.

Read `SKILL.md` at the root of the `scrapbook-photo-collage` repository completely, then follow its linked references only as needed. Preserve every supplied photo and avoid duplicates. Default artwork copy to English unless the user explicitly requests another language. Keep a clearly visible outer background around one bounded scrapbook island, structurally embed complete photo cards instead of pasting them over guessed windows, and balance photo-responsive motifs with freely associated playful keepsakes rather than restricting every prop to literal source content.

If the active model has no reference-image generation/editing tool, return the production-ready layout brief and prompt specified by the Skill. Do not claim to have rendered an image.
